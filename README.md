# melanieAzaidel.github.io

Personal professional website, hosted via [GitHub Pages](https://pages.github.com/).

## Structure

```
index.html      Homepage
css/style.css   Site-wide styles
js/script.js    Site-wide scripts
```

## Local preview

Open `index.html` directly in a browser, or serve the folder locally, e.g.:

```
npx serve .
```

## Deployment

This repo is a GitHub Pages user site (`<username>.github.io`), so pushes to the `main` branch are published automatically at https://melanieAzaidel.github.io.
